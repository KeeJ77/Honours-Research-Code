# Learning Bayesian Network Structure with SHAP: BIC Score Trees vs SHAP (XGBoost) Trees

Honours research project (B.Sc. Hons Big Data Analytics, University of the Witwatersrand, 2026).

The project asks whether **SHAP values from XGBoost models** can recover the structure of a discrete Bayesian network as well as the classical **BIC score**. Both methods build a maximum weight spanning tree over the variables, orient its edges, and are evaluated on how close the learned network is to the true one.

All of the code is in one notebook: **`Honours_Research_Full_Pipeline.ipynb`**.

---

## Research questions

| | Question | Ground truth | Metrics |
|---|---|---|---|
| **RQ1** | How do BIC trees and SHAP trees compare when the true network **is** a tree? | 10 synthetic tree-shaped networks built from ALARM | KL divergence, SHD (directed and skeleton) |
| **RQ2** | How do they compare on the real **ALARM** network, which has nodes with several parents? | Original ALARM network (37 nodes, 46 edges) | KL divergence, SHD, compared with BIC hill climbing |

Every experiment uses the sample sizes **n = 50, 100, 500, 1000, 2000, 3000, 5000, 6000**. RQ2 is repeated over **10 random seeds (42–51)**.

---

## Methods

**BIC tree**
1. For every ordered pair of variables, compute the BIC gain `w(i←j) = BIC(Xᵢ | Xⱼ) − BIC(Xᵢ)`.
2. Build a maximum weight spanning tree (Prim and Kruskal) on `max(w(i←j), w(j←i))`.
3. Point each edge in the direction with the larger BIC gain.

**SHAP tree**
1. Train **one XGBoost classifier per variable**, predicting it from all the others (37 models per dataset).
2. Use mean |SHAP| as the importance of each predictor for each target, and symmetrise: `W[i,j] = (S[i][j] + S[j][i]) / 2`.
3. Build a maximum weight spanning tree on `W`.
4. Orient each edge by **SHAP discrepancy** (ReX-inspired), `Δ = 1 − R²(actual, SHAP contribution)`. The direction with the lower Δ wins.

**Parameters and evaluation**
- The CPDs are learned with a Dirichlet prior (α = 1).
- **KL divergence:**
  - RQ1: Monte-Carlo KL from the ground truth to the learned network, using 500,000 samples.
  - RQ2: KL to ALARM on 20,000 reference samples.
- **SHD:** reversals + deletions + additions. Skeleton SHD ignores orientation.

## Getting started

### 1. Install

Python 3.13 was used.

```bash
pip install pgmpy shap xgboost networkx pandas numpy scikit-learn matplotlib jupyter
pip install pygraphviz        # optional: only needed for the Graphviz "dot" tree layouts
```

### 2. Data

The ALARM network (`alarm.bif`) comes from the [bnlearn Bayesian Network Repository](https://www.bnlearn.com/bnrepository/). Place it at `alarm.bif/alarm.bif` inside the project root. All other data (samples, structures, CPDs) is generated by the notebook.

### 3. Configure

Open the notebook and edit **only** the configuration cell (section 0.3):

```python
ROOT = r"path/to/this/repo"                  # folder that contains alarm.bif/
EXP  = os.path.join(ROOT, "Experiments")     # where all outputs are written
```

### 4. Run

- Run sections **0** and **1** first. They define everything the later sections use.
- Every experiment step is controlled by the `RUN` dictionary, and all steps start switched **off**. Set a step to `True` to run it.
- Steps read what earlier steps saved to disk, so you can re-run a single graph without retraining anything.

**Order for a full reproduction from scratch:** 2.1 → 2.8, then 3.1 → 3.5, then 4.1 → 4.4, then 5.2 → 5.5.

⚠️ **Runtime:** the SHAP steps train 37 XGBoost models for each dataset (hundreds of datasets in total), and the RQ1 KL step draws 500,000 samples per model. A full run takes many hours. The exploratory ReX step (5.1) is the slowest of all.

## Reproducibility

All randomness is seeded in the configuration cell:

| Purpose | Seed |
|---|---|
| ALARM samples for building the ground truths | 42 |
| Random root of each ground-truth tree | 42 |
| Random ground-truth CPDs (Dirichlet) | 42 (reset for each ground truth) |
| Synthetic datasets | 42 |
| XGBoost and train/validation/test splits (RQ1, RQ2 single seed) | 100 |
| RQ2 samples | `seed + n` (single seed: 42; repeated: 42–51) |
| RQ2 XGBoost (repeated experiment) | the experiment seed |
| KL reference samples / Monte-Carlo KL | 42 / 1 |

SHAP and XGBoost results can change slightly between library versions. Section 0.2 prints the versions used, and the Appendix lists known caveats.
